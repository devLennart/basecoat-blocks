# Feature Grid — features-01

A bordered feature grid with a wide highlight cell for proof points.

<picture><source media="(prefers-color-scheme: dark)" srcset="./preview-dark.png"><img src="./preview.png" alt="Feature Grid preview"></picture>

**Basecoat components:** Badge.

**Use:** Copy [`block.html`](./block.html) into a page that loads Tailwind CSS 4 and Basecoat 1.2.1. No JavaScript is required. Swap the copy and icons. Cells collapse from three columns to two to one. Replace the example stats with figures you can back up.

**Design rationale:** Hairline borders instead of cards keep a dense grid calm. The wide cell carries the numbers so the grid does not repeat itself.

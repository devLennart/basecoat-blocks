Create the new key before you revoke the old one. Both keys work at the same time, so you can roll out the new one gradually.1

  1. Open Settings → API keys and choose Create key with the same scopes.1
  2. Deploy the new key and watch Last used on the old key drop to zero.2
  3. Revoke the old key. Requests with it fail with 401 right away.3

Keys expire automatically only if you set an expiry date when you create them.1

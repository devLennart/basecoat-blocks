Components / Navigation / Sidebar

Navigation that stays in context.

Keep large content libraries legible with named groups and native disclosures. Use the nested tree to jump between sections or collapse an entire branch.

Introduction

Give each part of your product a home. A top-level group maps the territory; deeper levels reveal only the detail a reader needs right now.

Layout

The sidebar sits beside the document. On smaller screens, open it with the navigation button and dismiss it with the close control.

Breadcrumbs

Keep the path to the current page visible above the title, even when the navigation is closed.

Forms

Put related controls under one heading, and make every input's purpose clear to the person using it.

Accessibility

Native disclosure buttons work with keyboard navigation. Mark the current link with aria-current="page" and leave inactive branches free to close.
